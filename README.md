# 🚀 Data Structures

A collection of courses I completed as part of my journey in learning **Data Structures with C++ and C#**, through **Programming Advices**.

These courses cover fundamental and advanced data structures, performance analysis, and practical implementations.

---

## 📘 Data Structures Level 1 — C++

### 📚 Topics Covered

* Data Structures Fundamentals
* Time & Space Complexity (Big O)
* Arrays & Matrices
* Stacks & Queues
* Vectors & STL Basics
* Singly Linked Lists
* Doubly Linked Lists
* Circular Linked Lists
* Abstract Data Types (ADT)
* Maps & Unions
* Searching, Insertion & Deletion

### 🛠️ Technologies

* C++
* STL

---

## 📗 Data Structures Level 2 — C#

### 📚 Topics Covered

* Generic & Non-Generic Collections
* List, Dictionary, HashSet & Sorted Collections
* Hashtable & ObservableCollection
* Collection Interfaces
* Advanced Arrays & Jagged Arrays
* Tuples
* LINQ & Collection Operations
* Custom Collections
* `IComparable` & Object Comparisons
* BitArray & Bitwise Operations
* Trees & Tree Traversals
* Graphs
* Heaps & Priority Queue

### 🛠️ Technologies

* C#
* .NET
* LINQ

---

## 🎯 Learning Goals

* Understand and implement fundamental data structures
* Analyze performance using Big O
* Work with C++ STL and C# Collections
* Apply LINQ with different data structures
* Understand advanced structures such as Trees, Graphs, and Heaps
* Choose the appropriate data structure based on the problem
## 🎯 Purpose
Practice implementing core Data Structures from scratch without relying on STL containers.
